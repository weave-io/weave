This page is kept for existing links after the public docs consolidation. Current initialization guidance lives in [Configuration](../../configuration/), with the full command syntax in [CLI Reference](../../reference/cli/).

Current support note: use `weave init --scope local --yes` or `weave init --scope global --yes` depending on where config should live.

To install the native OpenCode 2 plugin at the same time, add
`--harness opencode2`. Local scope edits project JSONC. Global scope uses the
XDG OpenCode config.
