## Public packages

| Package | Release status | Use |
| --- | --- | --- |
| `@weaveio/weave-cli` | Stable and nightly | The `weave` CLI and Claude Code materialization. |
| `@weaveio/weave-adapter-opencode` | Stable and nightly | OpenCode plugin adapter. |
| `@weaveio/weave-adapter-claude-code` | Nightly only | Standalone Claude Code adapter. Stable users should use the CLI's `compose` command. |
| `@weaveio/weave-adapter-pi` | Nightly only | Implemented Pi extension; check the package peer requirement before installing. |

Core, config, and engine packages are implementation layers bundled into public artifacts. They are not supported direct installation targets.

## Install channels

Use `latest` for stable CLI and OpenCode installs. Use `nightly` for the nightly-only Claude Code and Pi packages or to test unreleased changes.

```sh
bun add --global @weaveio/weave-cli@latest
bunx @weaveio/weave-cli@latest --help
```

Pin the OpenCode plugin to an exact published version in `opencode.json` or `opencode.jsonc`:

```text
@weaveio/weave-adapter-opencode@<exact-version>
```

Pi installs through Pi's package command; see [Pi](../adapters/pi/).

## Verify a release

Use the exact package version and its registry metadata when you need reproducible setup. Do not treat a mutable channel name as a version pin. Published release records include the package tarball and checksum.
