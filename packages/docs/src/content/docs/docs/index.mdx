Weave is a harness-agnostic configuration layer for agents, categories, prompts, model preferences, tool policy, and workflows. You describe intent in `.weave/config.weave`; an adapter maps that intent to a supported harness.

## A minimal configuration

```weave
agent reviewer {
  description "Review changes for correctness"
  prompt "Review the current diff and report concrete findings."
  models ["claude-sonnet-4-5"]
  mode subagent
}

settings {
  log_level INFO
}
```

Validate it with the installed CLI:

```sh
weave validate
```
