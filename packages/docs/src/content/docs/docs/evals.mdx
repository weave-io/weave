---
title: Evals
description: Run Weave's text-only agent behavior suites.
---

`weave eval run` runs model-backed cases against Weave's rendered agent prompts. It scores behavior visible in assistant text; it does not validate user configuration or run a live harness session.

```sh
weave eval run --agent loom --case loom-route-backend-api
weave eval run --agent loom --case loom-route-backend-api --dry-run
```

Useful filters and controls include:

| Flag | Purpose |
| --- | --- |
| `--agent <name>` | Select a short agent name or suite ID. |
| `--model <id>` | Select one exact model ID. |
| `--case <id>` | Select one exact case ID, such as `loom-route-backend-api`. |
| `--dry-run` | Show the selected suites, models, and cases without making model calls. |
| `--raw-artifacts` | Write local-only raw artifacts for debugging. |

Use these suites to check routing, planning, review, research, and security behavior that appears in text. Verify tool calls and other harness behavior through the relevant adapter.

See the [CLI reference](../reference/cli/) for the complete command syntax.
