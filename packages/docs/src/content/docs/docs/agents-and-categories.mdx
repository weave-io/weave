## Choose an agent or category

Use an **agent** when you need a named role with its own prompt and model preferences. Use a **category** when you want routing metadata and a generated shuttle for a domain.

## Define an agent

```weave
agent reviewer {
  description "Reviews changes for correctness"
  prompt "Review the requested change and report concrete findings."
  models ["claude-sonnet-4-5", "gpt-5"]
  mode subagent
}
```

Supported fields include `description`, `prompt`, `prompt_file`, prompt appends, `models`, `mode`, `temperature`, `skills`, delegation `triggers`, `routing.delegation_exclude`, and `tool_policy`. Use either `prompt` or `prompt_file` for the primary prompt.

## Define a category

```weave
category frontend {
  description "UI and accessibility work"
  patterns ["src/**/*.tsx", "src/**/*.css"]
  models ["claude-sonnet-4-5"]
}
```

A category produces an agent named `shuttle-frontend`. Its prompt append, model preferences, and tool policy apply to that generated agent.

## Override a built-in

Declare an agent with the built-in name to change its public configuration. Keep the override in the project scope when it should apply to one project.

```weave
agent loom {
  prompt_append "Always state the next concrete action."
}
```

Run `weave prompt list` to see available names and `weave prompt inspect loom` to inspect the rendered prompt from the current project root.

See [the DSL reference](../reference/dsl/) for field types and [Configuration](../configuration/) for scope and merge rules.
